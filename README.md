# Clickaroo: Mouse Click Effects and Cursor Animations for Chrome

Clickaroo is a free Chrome extension that makes your mouse clicks visible. It draws an animation at the exact spot where you click, so people watching your screen recording, live stream, webinar or online class can follow what you are doing. A mouse click is the one action a screen recording never shows, and this fixes it.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/mjnldfdeejaimpkhbjpdopjbklcbkdgb?utm_source=github&utm_medium=readme&utm_campaign=clickaroo)** | **[Full guide and FAQ](https://www.addonschrome.com/extensions/clickaroo-mouse-effect-designer.html?utm_source=github&utm_medium=readme&utm_campaign=clickaroo)**

This repository is the public home for Clickaroo documentation, release notes and the issue tracker. The extension itself is distributed through the Chrome Web Store.

## Features

- Six click effects: wave, sparkle, burst, ring, bounce and pulse
- Your own color, size and speed
- Optional cursor trail
- Smooth 60 FPS animation
- Under 1 MB
- Interface in 35 languages
- No tracking: effects are rendered locally in your browser

## How to make mouse clicks visible on screen

1. Install Clickaroo from the [Chrome Web Store](https://chromewebstore.google.com/detail/mjnldfdeejaimpkhbjpdopjbklcbkdgb?utm_source=github&utm_medium=readme&utm_campaign=clickaroo).
2. Open the popup from the Chrome toolbar.
3. Pick one of the six effects, set the color and size, and switch the extension on.
4. Record or present as usual. Every click on a web page is marked with the animation.

There is nothing to configure in your recording software and nothing to edit afterwards: the effect is drawn on the page itself, so any screen recorder or streaming tool captures it.

You can try the effects live on the [Clickaroo page](https://www.addonschrome.com/extensions/clickaroo-mouse-effect-designer.html?utm_source=github&utm_medium=readme&utm_campaign=clickaroo).

## Good for

## Limits

Clickaroo works on web pages inside Chrome. It does not draw effects on the desktop or in other applications.
